# ABYSS LUMINA (아비스 루미나)

오리지널 심해 테마 빠칭코 **확률 시뮬레이터** (웹). 오락·학습용이며 실제 금전·결제·환전 기능이 없습니다.

> 본 프로젝트는 [PRD.md](PRD.md) §0 **오리지널리티 원칙**을 준수합니다. 특정 상용 기종의
> 그래픽·캐릭터·사운드·연출·명칭을 복제/추출/참조하지 않으며, 모든 심볼(심해 룬 크리스털 1~9),
> 배경, 연출은 코드로 직접 생성한 오리지널입니다. 자세한 출처는 [ASSETS_LICENSE.md](ASSETS_LICENSE.md).

## 빠른 시작

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
```

프로덕션 빌드/프리뷰:

```bash
npm run build
npm run preview
```

## 조작

| 키/버튼 | 동작 |
|---|---|
| `Space` / 발사 버튼 | 자동 발사 시작 / 정지 |
| `S` / 스킵 버튼 | 연출 스킵 (결과 즉시 표시) |
| 기종 선택 | MAX(1/319.7) · MID(1/199.8) · LIGHT(1/99.9) |

## 게임 구조

- **3행 3열 릴** — 심볼이 **오른쪽 → 왼쪽**으로 스크롤하며, 상 → 하 → 중 순서로 정지합니다.
- 상·하 가운데 심볼이 일치하면 **리치 성립** → 중앙 릴 서스펜스 → 리치 연출(5종).
- 가운데 열(페이라인) 3개가 모두 같으면 **대당첨**.
- 연출 엔진은 **이미 확정된 추첨 결과를 보여줄 뿐**, 결과에 영향을 주지 않습니다.

## CLI 확률 검증

```bash
npm run sim                        # 기본: abyss_max, 1천만 회전
npm run sim abyss_max 2000000 42   # specId, 회전수, 시드
```

이론값(스펙 JSON 에서 계산)과 몬테카를로 실측, 리치 신뢰도를 표로 출력합니다.

## 테스트

```bash
npm test          # Vitest — 엔진 결정성/확률 수렴/연출 독립성 (10 tests)
```

## 아키텍처

```
src/
├── engine/     # 순수 확률 로직 (렌더링 의존성 0, Node 단독 실행·테스트 가능)
├── sim/        # 이론값 계산 + 몬테카를로 + CLI
├── render/     # Canvas 2D 렌더 (릴/심볼/배경/이펙트/오케스트레이터)
├── specs/      # 기종 스펙 JSON (abyss_max/mid/light)
└── main.ts     # 부트스트랩 + 입력 + 메인 루프
```

핵심 원칙: `engine/` 은 브라우저 API·렌더러를 import 하지 않습니다 (PRD §3).

진행 현황과 자율 판단 기록은 [PROGRESS.md](PROGRESS.md) 참고.
